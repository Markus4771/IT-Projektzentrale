# Offene Lizenzentscheidung

Bevor das Repository öffentlich zur Weiterverwendung freigegeben wird, muss eine Softwarelizenz bewusst ausgewählt werden. Ohne Lizenz bleiben grundsätzlich alle Rechte beim Urheber.

Die Auswahl zwischen beispielsweise GPL, AGPL, MIT oder einer proprietären Lizenz ist eine geschäftliche und rechtliche Entscheidung und wird nicht automatisch getroffen.
